Descrição detalhada

Entidade projeto: identificador (chave primaria), nome, descricao, inicio e termino.

Cada atributo e um dominio que ja se valida sozinho, entao a entidade so guarda e devolve copias deles. O gestor (quem criou) fica no conteiner, nao aqui.
