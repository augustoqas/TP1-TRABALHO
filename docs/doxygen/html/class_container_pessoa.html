Descrição detalhada

Guarda as pessoas em memoria, indexadas pelo email.

So armazena; quem confere permissao e regra de negocio e o servico. A copia e proibida porque o main cria um unico conteiner e passa o ponteiro para as controladoras; uma copia criaria um segundo armazenamento e os dados divergiriam.
