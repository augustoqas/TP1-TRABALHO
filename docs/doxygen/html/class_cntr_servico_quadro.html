Descrição detalhada

Servico de quadros (servicos 11 a 15): aplica as regras de Quadro.

Usa quatro conteineres passados por setter: pessoas (cadastro e papel do usuario), projetos (o quadro so e criado em projeto existente), quadros e cartoes (para o WIP e para recusar excluir quadro com cartoes). So guarda os ponteiros; o main mantem os conteineres vivos. Qualquer usuario cadastrado pode ler e listar; criar, atualizar e excluir exigem papel GESTOR. Cada quadro pertence a exatamente um projeto, fixado ao criar. Se faltar um conteiner necessario, o metodo retorna false.
