Descrição detalhada

Guarda os quadros em memoria e o identificador do projeto de cada um.

O projeto fica aqui porque Quadro nao tem esse atributo; cada quadro pertence a exatamente um projeto, fixado na inclusao. Nao confere regra de negocio, e a copia e proibida pelo mesmo motivo de ContainerPessoa.
