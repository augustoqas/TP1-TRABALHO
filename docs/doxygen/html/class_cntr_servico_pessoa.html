Descrição detalhada

Servico de pessoas (servicos 1 a 5): aplica as regras de Pessoa.

Usa tres conteineres passados por setter: pessoas, projetos (para saber quem e gestor) e cartoes (para saber quem e desenvolvedor). So guarda os ponteiros; o main mantem os conteineres vivos. Qualquer usuario cadastrado pode ler, atualizar, excluir (ate a si mesmo) e listar qualquer pessoa; criar nao exige sessao. Se faltar um conteiner, o metodo retorna false: criar, ler e listar precisam so do de pessoas; atualizar e excluir precisam dos tres para checar os vinculos.
