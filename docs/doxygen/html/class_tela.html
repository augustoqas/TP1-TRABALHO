Descrição detalhada

Funcoes de tela em modo texto usadas por todas as controladoras de apresentacao, para que todas as telas tenham a mesma cara.

Tudo e estatico. Cada pergunta sai numa linha propria e nada digitado e repetido na tela (a senha nunca aparece). Digitar 0 em um campo cancela; nenhum dominio aceita "0", entao nao ha conflito.

Exemplo (tela de quadros):

int opcao = Tela::lerOpcao("MENU DE QUADROS", {"Criar quadro", "Voltar"});
if (opcao == 0) {
return; // a entrada acabou
}
Tela::titulo("CRIAR QUADRO");
Identificador identificador;
if (Tela::lerCampo("Identificador", "3 letras e 3 digitos", identificador) != Tela::Leitura::LIDO) {
return; // cancelou ou a entrada acabou
}
Limite limite; // setValor recebe int
if (Tela::lerCampoInteiro("Limite", "1 a 25", limite) != Tela::Leitura::LIDO) {
return;
}
if (!servico->criar(usuario, projeto, quadro)) {
Tela::falha("Nao foi possivel criar o quadro.", {"usuario nao e GESTOR", "projeto nao existe", "identificador ja existe"});
}

◆ lerCampo()

template<typename Dominio>
Tela::Leitura Tela::lerCampo ( const std::string & rotulo,
const std::string & dica,
Dominio & dominio )
static

Le um campo de dominio, pedindo de novo ate o valor ser valido.

Serve para qualquer dominio com setValor(std::string) que lanca std::invalid_argument para valor invalido. A dica aparece entre parenteses. Se o usuario digitar 0, ja mostra "Operacao cancelada" e retorna CANCELADO.

Parâmetros
rotuloNome do campo mostrado na pergunta.
dicaFormato esperado, mostrado entre parenteses.
dominioSo e preenchido quando o retorno e LIDO.
