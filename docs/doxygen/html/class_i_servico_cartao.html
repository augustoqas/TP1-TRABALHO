Descrição detalhada

Servico de cartoes (servicos 16 a 26). Criar, atualizar e excluir: so GESTOR.

Tempo de ciclo = termino - inicio (FAZENDO ate FEITO). Lead time = termino - entrada (A FAZER ate FEITO).
