Descrição detalhada

Servico de projetos (servicos 6 a 10): aplica as regras de Projeto.

Usa tres conteineres passados por setter: pessoas (para saber se o usuario esta cadastrado e qual o papel dele), projetos e quadros (para recusar excluir projeto com quadros). So guarda os ponteiros; o main mantem os conteineres vivos. Qualquer usuario cadastrado pode ler e listar; criar, atualizar e excluir exigem papel GESTOR. Quem cria vira o gestor do projeto. Se faltar um conteiner necessario, o metodo retorna false: ler e listar precisam dos de pessoas e projetos; excluir precisa tambem do de quadros.
