Descrição detalhada

Guarda os projetos em memoria e o email do gestor de cada um.

O gestor fica aqui porque Projeto nao tem esse atributo. Nao confere regra de negocio, e a copia e proibida pelo mesmo motivo de ContainerPessoa.
